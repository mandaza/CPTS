## Web Reconnaissance — Introduction

First stage of the **Information Gathering** phase: systematically collect info about a target site/web app before deeper analysis.

## Goals
- **Identify assets** — pages, subdomains, IPs, technologies (the full online footprint).
- **Discover hidden info** — backup files, config files, internal docs → entry points.
- **Analyse the attack surface** — tech/configs/entry points → where it's weak.
- **Gather intelligence** — staff, emails, patterns → feeds exploitation & social engineering.

## Two methodologies

### Active recon — you interact directly with the target
Higher detail, **higher detection risk** (can trip IDS/firewalls).
| Technique | What | Tools | Detection |
|---|---|---|---|
| Port scanning | Open ports/services | Nmap, Masscan | **High** |
| Vuln scanning | Probe known vulns (sends payloads) | Nessus, OpenVAS, Nikto | **High** |
| Network mapping | Topology/hops | traceroute, Nmap | Med–High |
| Banner grabbing | Read service banners | netcat, curl | Low |
| OS fingerprinting | Detect OS | Nmap `-O`, Xprobe2 | Low |
| Service enumeration | Service **versions** | Nmap `-sV` | Low |
| Web spidering | Crawl pages/dirs/files | Burp/ZAP spider, Scrapy | Low–Med |

### Passive recon — no direct interaction, use public sources
Stealthier (**very low** detection) but less complete.
| Technique | What | Tools |
|---|---|---|
| Search engines | Dorking, OSINT | Google, Bing, **Shodan** |
| WHOIS | Domain registration details | `whois` |
| DNS | Subdomains, mail servers, infra | `dig`, `nslookup`, `host`, dnsenum, fierce, dnsrecon |
| Web archive | Historical site snapshots | Wayback Machine |
| Social media | Staff/role intel | LinkedIn, Twitter, OSINT tools |
| Code repos | Exposed creds/secrets | GitHub, GitLab |

## Notes to self
- **Active = touches target (detectable); Passive = public sources only (stealthy).** Start passive, escalate to active.
- Even "low risk" active techniques (banner grab, `-sV`) can still be **logged**.
- First tool the module dives into next: **WHOIS**.
