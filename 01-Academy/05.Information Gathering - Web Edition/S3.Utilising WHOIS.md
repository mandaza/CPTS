## Utilising WHOIS

```bash
sudo apt install whois -y        # if missing
whois facebook.com
```

## Reading a record — what each field tells you
- **Registrar + Creation/Expiry dates** → legitimacy & age. Old domain + distant expiry = established/legit; **days-old** registration = suspicious.
- **Registrant/Admin/Tech org + contact** → who's behind it (e.g. `Meta Platforms, Inc.` / `Domain Admin`).
- **Domain Status** (`clientTransferProhibited`, `serverUpdateProhibited`, …) → locks against unauthorized change/transfer/delete = security-conscious owner.
- **Name Servers** → in-domain NS (e.g. `A.NS.FACEBOOK.COM`) = org runs its own DNS; third-party NS points at the hosting provider.

## Red flags (phishing/malware indicators)
- Very **recent registration** date.
- Registrant **hidden by privacy service** / free anonymous email.
- Name servers on a **bulletproof hosting** provider.
- Registrar with **lax abuse policies**; registrant in a high-cybercrime location.
- Across campaigns: domains registered in **clusters** before attacks, **shared name servers** = common infra → pivot to find more of their domains.

## Notes to self
- WHOIS alone rarely gives individual employees or vulns → **combine with DNS, OSINT, etc.**
- For a pentest target, harvest: **name servers** (→ DNS enum), org name (→ subdomain/asset hunting), contact emails (→ phishing/user lists), registration dates.
- Shared NS / registrant details are a **pivot**: find other domains owned by the same target.
