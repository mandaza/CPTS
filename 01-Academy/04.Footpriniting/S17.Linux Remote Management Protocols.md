## Linux Remote Management

## SSH (TCP 22)
- Encrypted remote shell/file transfer/port-forwarding. **OpenSSH** = the usual server. **SSH-2** secure; **SSH-1** weak (MITM).
- Auth methods: password, **public-key**, host-based, keyboard-interactive, challenge-response, GSSAPI.
- Banner tells you version + protocol: `SSH-2.0-OpenSSH_8.2p1` = SSH-2 only, OpenSSH 8.2p1. `SSH-1.99-...` = accepts both SSH-1 and SSH-2.

### Dangerous `sshd_config` settings
`PasswordAuthentication yes` (brute-forceable) · `PermitEmptyPasswords yes` · `PermitRootLogin yes` · `Protocol 1` (weak crypto) · `X11Forwarding yes`.

### Footprinting
```bash
# audit algorithms + banner + known weaknesses
ssh-audit <TARGET>                 # or ./ssh-audit.py <TARGET>

# see which auth methods the server allows
ssh -v <user>@<TARGET>
# force password auth (for brute-forcing)
ssh <user>@<TARGET> -o PreferredAuthentications=password
```

## Rsync (TCP 873)
- Fast file copy/backup (delta transfer). Shares can sometimes be listed/pulled **without auth**.
```bash
nmap -sV -p873 <TARGET>                       # detect (protocol 31)
nc -nv <TARGET> 873                           # then type: #list   -> lists shares
rsync -av --list-only rsync://<TARGET>/<share>  # enumerate a share
rsync -av rsync://<TARGET>/<share> ./loot/      # pull files
# over SSH: add  -e ssh   (or  -e "ssh -p2222")
```
> Look for `.ssh/`, `secrets.yaml`, configs. Always check password reuse.

## R-Services (TCP 512 exec, 513 login, 514 shell)
- Legacy Unix remote access (Solaris/HP-UX/AIX), replaced by SSH. **Unencrypted** → MITM-able. r-commands: `rcp`, `rsh`, `rexec`, `rlogin`, `rwho`, `rusers`.
- **Trust files bypass auth:** `/etc/hosts.equiv` (global) and `~/.rhosts` (per-user), format `<user> <host>`. A **`+`** = wildcard (any user / any host) → login with no credentials.
```bash
nmap -sV -p512,513,514 <TARGET>
rlogin <TARGET> -l <user>          # log in if .rhosts/hosts.equiv trusts us
rwho                               # who's logged in across the network (UDP 513 broadcasts)
rusers -al <TARGET>                # detailed logged-in users -> harvest usernames
```

## Notes to self
- SSH banner = free version + protocol intel; feed it to `searchsploit`.
- Rsync: `nc <ip> 873` → `#list` is the quickest unauth share check.
- A `+` in `.rhosts`/`hosts.equiv` = instant credential-less `rlogin`.
- Every one of these is a **password-reuse** opportunity — try harvested creds everywhere.
