## MySQL

- Open-source relational DB (Oracle). **MariaDB** = community fork of MySQL. Client-server, default **TCP 3306**.
- Backs dynamic web apps (**LAMP** / **LEMP**). WordPress etc. store posts, users, **password hashes** in it — normally bound to localhost, but admins sometimes expose it externally by mistake.
- Passwords are usually hashed by the app (PHP) before storage, but can be plaintext.

## Dangerous settings (`/etc/mysql/mysql.conf.d/mysqld.cnf`)
- `user` / `password` / `admin_address` → stored in **plaintext**; readable if you get file read or a shell → full DB access.
- `secure_file_priv` → limits import/export (empty value = can read/write files anywhere).
- `debug` / `sql_warnings` → verbose errors leak info, aid SQLi.

## Footprinting
```bash
# scan + run all mysql NSE scripts
sudo nmap <TARGET> -sV -sC -p3306 --script mysql*
```
NSE gives version, auth plugin, and brute/enum results.
> **Verify manually** — NSE often false-positives "empty password / valid user" on MySQL 8. Always test the login yourself.

## Interacting
```bash
mysql -u root -h <TARGET>                  # try no password
mysql -u root -p<PASSWORD> -h <TARGET>     # NO space between -p and the password
```

## Core SQL commands
```sql
show databases;                 -- list DBs
use <database>;                 -- select a DB
show tables;                    -- tables in current DB
show columns from <table>;      -- columns of a table
select * from <table>;          -- dump a table
select * from <table> where <col> = "<string>";
select version();               -- server version
```

## Notes to self
- Default DBs present on every server: `information_schema`, `mysql`, `performance_schema`, `sys` (metadata/management). Real data is in the *other* DBs.
- The juicy target is usually the app's own DB → `user`/credentials tables.
- `mysql` (DB) `user` table holds account hashes — crack offline.
