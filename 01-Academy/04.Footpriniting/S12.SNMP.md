## SNMP

- Monitors/configures network devices over **UDP**. Port **161** = queries, **162** = traps.
- **v1 / v2c** = no encryption, community string in cleartext. **v3** = auth + encryption.
- **Community string** = password for access. Read default = **`public`**, write = often `private`.
- **OID** = dotted address of one item in the MIB tree (e.g. `.1.3.6.1.2.1.1.1.0`).

## Dangerous settings (`/etc/snmp/snmpd.conf`)
- `rwuser noauth` → full read/write, no auth.
- `rwcommunity <string> <IP>` → full tree access from anywhere.

## Workflow
```bash
# know the string → dump everything
snmpwalk -v2c -c public <TARGET>

# don't know it → brute-force
onesixtyone -c /usr/share/seclists/Discovery/SNMP/snmp.txt <TARGET>

# have the string → fast OID enum
braa public@<TARGET>:.1.3.6.*
```

## High-value OIDs
- `.1.3.6.1.2.1.1.1.0` → OS / kernel banner
- `.1.3.6.1.2.1.1.4.0` → sysContact (email/username)
- `.1.3.6.1.2.1.1.5.0` → hostname
- `.1.3.6.1.2.1.25.6.3.1.2` → installed packages (version intel)
- `.1.3.6.1.2.1.25.4.2.1.2` → running processes

## Notes to self
- UDP → scan with `sudo nmap -sU -p161 <TARGET>`.
- Always try `snmpwalk -v2c -c public` first; timeout = wrong string/version.
