# Start Here

## One-time setup (5 minutes)
1. **Settings → Community plugins → Turn on community plugins**
2. Browse and install + enable: **Templater**, **Dataview**, **Obsidian Git**, and optionally **Excalidraw**
3. **Templater settings**: set *Template folder location* to `Templates`
4. **Dataview settings**: turn on *Enable JavaScript Queries* (optional) and *Enable Inline Queries*
5. **Obsidian Git**: first run `git init` in this folder (Terminal), create a **private** repo, add it as `origin`, then enable auto-commit every 30 minutes

## Daily flow
1. New note in `02-Boxes/` named after the box
2. Insert template: command palette → *Templater: Open insert template modal* → `Box`
3. Take notes while you work, not afterwards
4. Update `status`, `hours`, `hints` and `confidence` in the properties when done
5. Check `00-Dashboard/Progress`

## Rules for publishing
- Only write up **retired** boxes
- Never publish flags, passwords or hashes
- Never publish Academy module answers or anything from the CPTS exam (NDA)
- Copy the note into `05-Blog-Drafts/` and clean it up there, so your raw notes stay raw

## Delete after the first week
`02-Boxes/Example Box - delete me.md` is only there so the dashboard has something to show.
